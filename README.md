# ✈️ SkyNav AI - Autonomous Flight Booking Agent

SkyNav AI is an intelligent, conversational flight booking assistant built with Python and Streamlit. It automates flight searching, interactive seat selection, secure 2-Factor Authentication via Email OTP, and instant PDF E-Ticket generation.

---

## 🌟 Key Features

* **✈️ Flight Search & Selection:** Interactive searching for major flight routes with real-time pricing.
* **🪑 Seat Allocation:** Choose preferred seats across Business Class, Extra Legroom, and Standard Economy.
* **🔒 Email OTP Verification:** Automated OTP dispatch via Gmail SMTP for transaction security.
* **📄 Instant PDF Ticket Generation:** Uses ReportLab to dynamically build downloadable official E-tickets.
* **💬 Conversational UI:** Clean, intuitive chatbot interface powered by Streamlit.

---

## 🛠️ Tech Stack

* **Frontend Framework:** Streamlit
* **PDF Engine:** ReportLab
* **Email Service:** Python `smtplib` & `email.mime`
* **Language:** Python 3.10+
